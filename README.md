# Telegram Bot for Technical Career  Guidance
## Описание:
_**Telegram-бот**_, который помогает определить подходящие технические специальности
на основе ответов на простые вопросы.

## 🎯 Цель проекта:
Создать _**Telegram-бота**_, который поможет студентам и школьникам определить,
какая техническая специальность им ближе.

## #️⃣ Технологии:
- Язык: **C# (.NET 9.0)**
- Библиотека: **Telegram.Bot**
